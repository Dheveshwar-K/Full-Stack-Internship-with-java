# Full-Stack-Internship-with-java 
 
# Day 1 Task
1. Create a webpage with a system status banner.
2. Display a welcome message when the page loads.
3. Use an arrow function to display and update the banner message.
4. Use a Promise to simulate checking the system status.
5. Display different messages based on the system status:
   - System is Online
   - System is Checking...
   - System is Offline
6. Change the banner background color based on the status.
7. Add a button called "Check System Status".
8. When the user clicks the button, check the system status and update the banner dynamically.
